00

系统边界与三方协同

边界不是"整台设备"，而是"一次训练中被使用的那个闭环"。先把包含与不包含写清，再写三方怎么协同，否则需求会一路膨胀到诊断、处方与健康档案。

系统包含
  • 采集前端：肌电与体征采集、环境传感阵列
  • 决策单元：边缘混合决策、意图识别与仲裁
  • 执行单元：外骨骼、功能电刺激、触觉反馈
  • 能源与监护：电源管理、旁路式安全监护
  • 配置与接口：参数配置、日志导出
系统不包含
  • 诊断与治疗决策：由医师在系统外完成
  • 云端长期健康档案：只做训练日志，不建病历
  • 器件级 BOM 与机械图纸：属于制造环节

三方协同：不是一次设定，终身不变

角色在系统中的位置职责权限边界
治疗师 / 康复医师系统外设定，系统内生效设定安全边界、辅助等级与训练处方；按复评结果调整。可改限幅与等级；不可越过硬限幅。
患者诊室 / 社区站 / 居家发起动作、使用助力、随时终止；居家场景自主训练。可否决任何一次出力；不可改处方。
运维技师系统外维护校准传感器、处理故障、更换模块。可进检修态；训练中不可介入控制。

三方协同的判据：每次参数变更都留下"谁改的、改前改后、依据哪次评估"三条记录。没有记录，等于没改。

01

三条业务与业务需求

三条业务自下而上，下层是上层的前提。业务需求只写"业务上必须发生什么"，不写技术实现；编号 BR-01 至 BR-12 后续全部由相关方需求与系统需求承接。

编号所属业务业务需求承接去向
BR-01基础训练全程连续采集心率、血压、呼吸与体温，越界可判定。FR-08 / PR-3
BR-02基础体征越界时先限制增强，未恢复即强制停机。SSR-9 / SSR-12
BR-03基础训练前完成电极阻抗、电量、传感器与链路的自检，任一未通过不进训练。FR-12 / ST-0
BR-04原生患者的主动发力必须可被测量并作为助力依据。FR-03 / PR-2
BR-05原生助力只叠加在主动发力之上，不得替代患者发起动作。FR-04 / PR-4
BR-06原生残存的感觉与运动通路受到保护，训练沿通路进行。SS-04 / FR-07
BR-07原生训练强度与疲劳可评估，疲劳即停而不是凑次数。FR-10 / PR-6
BR-08增强覆盖评估测量、被动助动、主动辅助、抗阻训练、日常代偿五类任务。FR-01 / FR-02
BR-09增强辅助等级由治疗师按处方设定，训练中可按评估结果调整。FR-02 / IR-4
BR-10增强助力随患者发力增减，不缺省为恒定输出。PR-4 / SW-06
BR-11增强抓握与伸展的缺口力矩可补足，动作可完成。FR-06 / PR-2
BR-12增强每次训练留下可复盘记录，供治疗师与家属查看。FR-10 / FR-11

四条硬约束：从业务直接落到架构

编号约束架构落点
BC-1训练安全优先级最高，效果目标不得与之交换。独立监护旁路 + 硬件限幅 + 分级降级。
BC-2控制权可切换，人有最高否决权。物理急停硬线直达切断回路（SSR-6）。
BC-3满足医用生物相容性与电磁兼容。电极材料、贴片更换、线缆屏蔽与无线频段受限。
BC-4不破坏神经自主调节，关停后仍能维持基本生命活动与体位。断电卸载、无源结构承重、机械硬限位。
02

八类相关方五方推动 · 三方审查

相关方不是通讯录，而是"能对系统说不的人"。五方推动方案往前走，三方握着审查与否决权；每条"不得""必须"都要能回溯到某个审查方，每条功能都要能回溯到某个推动方。

序号相关方姿态关注点对系统的作用
01使用者（偏瘫患者）推动安全、舒适、实际功能提升知情同意、随时终止、隐私保护
02研发小组推动架构合理、可验证、可迭代定义方案、推进版本迭代
03治疗师 / 康复医师推动康复效果、体征稳定、参数可调评估适配、设定阈值与处方
04医疗器械监管机构审查安全性、合规性、风险可控审批准入、必要时叫停
05伦理审查委员会审查人机接口的伦理边界、风险收益平衡可否决试验方案
06生产与供应链厂商推动可制造性、成本、批次一致性按图纸生产、提出工艺限制
07数据安全管理方审查神经与健康数据不泄露、不滥用加密、权限、留痕审计
08患者家属推动居家场景的安全与异常介入知晓风险、协助处置
03

二十四条相关方需求

每方三条，一条讲"要什么"，一条讲"不能怎样"，一条讲"怎么证明"。写法上统一用"应/不得"，避免"尽量""尽可能"这类不可验收的措辞。

编号相关方需求验收方式
StR-01患者训练中不得出现非预期的过冲、牵拉或痉挛。助力跟随测试 + 主观反馈
StR-02患者应能随时终止本次助力并退回纯自主。急停与退出演练
StR-03患者原始肌电与体征数据不得离开本地设备。抓包与日志审计
StR-04研发小组架构应支持按子系统独立测试与替换。接口图评审 + 单系统测试
StR-05研发小组每条需求应可追溯到上游诉求与下游组件。追踪矩阵抽查
StR-06研发小组版本迭代不得改变已验收的安全边界。回归测试集
StR-07治疗师应能按处方设定辅助等级与力矩、角度限幅。参数下发与生效验证
StR-08治疗师训练记录应可复盘到每个回合的意图与助力曲线。日志导出与回放
StR-09治疗师系统不得在体征越界时继续增强输出。越界注入测试
StR-10监管机构安全相关功能应有失效默认安全的设计证据。设计评审 + 故障注入
StR-11监管机构风险分析应覆盖控制动作的四类失效。STPA 报告
StR-12监管机构软件变更应留存版本、验证与审批记录。配置管理审计
StR-13伦理委员会人机接口不得以增强健存功能为目的。适应人群与用途审查
StR-14伦理委员会患者知情同意应包含退出机制与数据用途。知情同意书评审
StR-15伦理委员会试验方案应有风险收益比论证与中止条件。方案评审
StR-16生产与供应链关键模块应可在不重标定整机的前提下更换。换件后自检通过
StR-17生产与供应链批次一致性应可抽检到电极与减速器的关键参数。批次抽检报告
StR-18生产与供应链结构设计不得依赖不可采购的定制件。BOM 评审
StR-19数据安全方健康与神经数据应加密存储、分级授权、全程留痕。权限与审计抽查
StR-20数据安全方采集应最小必要，诊断无关字段不得采集。字段清单核对
StR-21数据安全方云端不得下发任何实时控制指令。链路检查
StR-22家属应知晓急停位置、异常表现与协助流程。培训与操作考核
StR-23家属不得擅自修改阈值与模式。权限验证
StR-24家属患者出现不适时应可一键切断增强。急停演练
04

四层场景S1 — S4

场景按"谁在决策、尺度多长"分四层：使命层定成功判据，环境层定监督强度，任务层定练什么，交互层定一次回合怎么走。上层给下层设约束，下层向上层交证据。

S1　使命层　MISSION
功能恢复 · 生活回归 · 医疗体系

康复目标与支付环境：上肢功能评分提升、日常生活动作可自理、训练可在三级照护体系内接续。判据是"能否回到某个生活动作"，不是"训练了多少次"。

S2　环境层　ENVIRONMENT
诊室 / 社区站 / 居家：监督强度不同

诊室有治疗师在场，可设参数、可随时接管；社区站有指导员，监护强度中等；居家由家属在场、患者自主训练，系统必须更保守——限幅更紧、告警更显性、退出更早。

S3　任务层　TASK
五类任务，各有辅助等级与限幅

评估测量（测残存发力与关节活动度）、被动助动（机器完成轨迹，患者感知）、主动辅助（患者发力、机器补差）、抗阻训练（反向加载）、日常代偿（抓握与够取实物）。每类任务对应不同的辅助等级上限。

S4　交互层　INTERACTION
一次回合：自检 → 意图 → 出力 → 回采 → 结束

单次交互是风险最容易定位的一层：佩戴自检、意图采集与确认、仲裁与辅助出力、反馈回采与监视、结束与安全退出。典型场景与风险清单都落在这一层。

05

七个运行状态

状态机只做一件事：出了问题只往"少帮忙"的方向退。任何一次迁移都必须先确认安全位姿，再换模式。

ST-0自检待机→ ST-1就绪→ ST-2训练→ ST-3降级→ ST-4强制停机→ ST-5故障安全→ ST-6检修
状态名称含义进入与退出条件
ST-0自检待机上电后不输出任何助力，逐项检查电极阻抗、电量、传感器与链路。四项全过进 ST-1；任一不过停在 ST-0 并显性提示。
ST-1就绪已佩戴、已通过自检，等待开始；执行器保持安全位姿。治疗师或患者确认开始进 ST-2。
ST-2训练按当前任务与辅助等级出力；监护旁路全程运行。越界或置信度不足进 ST-3；急停进 ST-5；到次数或疲劳进 ST-1。
ST-3降级限幅收紧、只保留有限辅助或纯自主，告警显性化。恢复且人工确认回 ST-2；未恢复进 ST-4。
ST-4强制停机停止增强输出，执行器回安全位姿，等待处置。排除原因并经治疗师确认回 ST-1。
ST-5故障安全急停锁定：硬线切断输出，状态不可软件复位。仅检修后可复位进 ST-6 → ST-0。
ST-6检修维护模式，可换件与标定，训练功能禁用。换件与自检通过后回 ST-0。
06

接口清单与计算分区

接口写清"谁跟谁、传什么、断了怎么办"。计算分区写清"什么必须在本地、什么可以上云"。

编号接口内容断连策略
IR-01电极—皮肤差分肌电、阻抗检测回路阻抗异常即停增强并告警
IR-02臂环—外骨骼意图与关节指令、状态回读超时冻结输出，回安全位姿
IR-03外骨骼—边缘主机角度、力矩、电流与限幅状态断连即执行器卸载
IR-04治疗师端—边缘主机处方、辅助等级、限幅与身份认证离线沿用上次已批准的参数
IR-05边缘—云端日志汇总、模型与策略下发、远程复盘断网继续训练，恢复后补传
IR-06急停—切断回路硬线电平信号，直达执行器断电断线即视为按下（失效安全）
本地边缘必须做的四件事

① 滤波与特征；② 意图分类；③ 安全规则判定；④ 关节控制。四项都在 200 ms 内闭合，断网可继续训练，原始信号不上传。

云端只做四件非实时的事

日志汇总、模型更新、策略下发（治疗师调等级）、远程复盘。云端不进控制环，也不下发任何实时指令。

07

冲突与假设

概念定义阶段最有价值的部分，是把互相打架的诉求摆到桌面上，并说明本次取哪一边、为什么。

五处冲突与取舍

冲突表现本次取舍
安全 vs 训练强度限幅越紧越安全，但训练效果需要足够力矩。安全优先（BC-1）：限幅由治疗师设定，系统不得自行放宽。
助力 vs 主动发力助力过大患者省力但变成被动，过小则完不成动作。以肌电为相位基准，助力只补差（PR-4）。
数据上传 vs 隐私远程复盘需要数据，隐私要求原始信号不出本地。只上传统计特征与日志，原始信号不出设备。
冗余双通道 vs 成本双通道与独立监护显著增加成本与重量。安全功能必须冗余，非安全功能单通道。
穿戴轻便 vs 传感精度自由度与电极越多越准，但重量与穿戴时间上升。先保肘腕两自由度与四通道肌电，其余留作扩展。

六条设计假设

编号假设若不成立
A-1患者残存肌电可被体表电极稳定采集。退到 IMU + 力传感的动作级判断。
A-2电极阻抗在 30 min 训练内不显著漂移。缩短单次时长，中途重新自检。
A-3诊室或居家均有治疗师处方或家属在场。居家模式限幅收紧，禁用抗阻任务。
A-4居家电源与网络可用，但允许断网。纯本地闭环，训练记录延后补传。
A-5患者为单侧偏瘫、认知可配合指令。不纳入适应人群，转由治疗师一对一操作。
A-6急停按钮始终在可触及范围内。增设家属侧副急停，并在自检中检查可达性。
